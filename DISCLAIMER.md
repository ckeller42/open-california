# Disclaimer & Notice

## Why this project exists

I want to use my **own** VW California camper from **Linux and other open platforms**. The
vendor app runs only on iOS and Android — there is no Linux client, and no official way to
read or control the unit from open systems. **That interoperability does not exist without
this project; that is the only reason it exists.** It is intended for use on the owner's own
vehicle.
